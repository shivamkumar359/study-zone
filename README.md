# Study Zone

Study Zone is a free learning platform that helps students quickly discover high-quality educational videos through a clean and distraction-free interface. It simplifies learning by organizing reliable resources in one place for easy, self-paced study.

## 🔗 Live Demo
https://shivamkumar359.github.io/study-zone/

## 🚀 Features
- Search educational topics instantly
- Curated YouTube learning resources
- Clean and distraction-free UI
- Responsive design
- Privacy-enhanced video embedding

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- YouTube Data API
- GitHub Pages

## 📌 Project Type
Frontend Web Application

## 📄 Disclaimer
Study Zone does not host or upload any video content. All videos are embedded from publicly available YouTube sources, and credit belongs to the original creators.
